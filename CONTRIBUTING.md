# Contributing

Thanks for helping improve Finance Vault.

1. Open an issue for significant behavior or architecture changes.
2. Keep plaintext financial data, credentials, and recovery phrases out of commits and issues.
3. Make focused changes with tests or clear verification steps.
4. Run `npm run build` and `npm run worker:check` from `next-app/`.
5. Explain security, privacy, migration, and quota impact in the pull request.
